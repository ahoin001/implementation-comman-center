# Implementation Command Center

Ops home for Web Scribble client launches. Teammates share implementations from design through import, SSO, SmartWay training, and go-live. Clients use a token link to send docs, credentials, and assets.

**Audience:** implementation specialists at a desk, all day, in a browser.

**Mode:** Operate. Scanability and quiet chrome beat expression. Brand lives in the paper, the type, and one authored object per region.

**Surfaces:** Projects, My Projects, project detail (launch board, deliverables, notes), Archive, Settings, Auth, Client Intake. Dashboard and Calendar exist and stay on-system even when hidden from nav.

**Not:** a marketing site, a wallpaper engine, or Cleanly the product. Cleanly is the visual world only.
